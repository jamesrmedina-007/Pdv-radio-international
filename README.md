# PDV Radio Internacional

Starter website for PDV Radio Internacional, designed for GitHub Pages.

## Files
- `index.html` — page content
- `styles.css` — visual design and mobile layout
- `script.js` — live radio configuration and mobile navigation
- `CNAME` — custom domain for GitHub Pages

## Before publishing
1. Replace the placeholder contact email in `index.html`.
2. Add the official direct radio stream URL to `STREAM_URL` in `script.js`.
3. Replace the temporary PDV text logo with the official logo when available.
4. Add official program names and schedules.
5. Add approved photos and ministry information.

## Deploy with GitHub Pages
1. Create a GitHub repository, for example `pdv-radio-internacional`.
2. Upload these files to the repository root.
3. In GitHub open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Under **Custom domain**, enter `pdvradiointernacional.org`.
7. Update the domain's DNS records with the GitHub Pages records shown by GitHub.
8. After DNS verifies, enable **Enforce HTTPS**.

Do not change the current site's DNS until the new GitHub Pages preview has been fully tested.
